Overview
This repository contains a complete collection of professional cybersecurity internship reports documenting my learning journey through fundamental and practical offensive security concepts. The reports cover networking, Linux, reconnaissance, vulnerability assessment, web application security, exploitation, password security, and a final capstone penetration testing project.
Each task includes detailed documentation, methodology, screenshots, findings, analysis, and remediation recommendations where applicable. To reinforce practical skills, relevant TryHackMe rooms were completed alongside the internship tasks.
Learning Objectives
Throughout this internship, the primary objectives were to:
Build a strong foundation in cybersecurity principles.
Understand networking concepts and protocols.
Gain proficiency in Linux administration and command-line operations.
Perform reconnaissance and information gathering.
Conduct network scanning and service enumeration.
Identify and assess vulnerabilities.
Understand web application security concepts.
Perform hands-on exploitation in controlled environments.
Learn password security and cracking techniques.
Develop professional penetration testing reporting skills.
